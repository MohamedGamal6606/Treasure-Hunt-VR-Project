# 🌴 Unity Project – VR Treasure Hunt

## 📌 Overview
This project is a Unity-based application/game developed using **Unity Engine**.  
It features a VR treasure hunt experience with 3 main scenes:
1. Ship Scene.
2. Island Scene.
3. Cave Scene.

---


### Installation
1. Clone the repository:
  ```git clone https://github.com/MohamedGamal6606/Treasure-Hunt-VR-Project```

2. Open Unity Hub  
3. Click "Open Project"  
4. Select the project folder  

---

## ▶️ How to Run
- Open the Main Menu from Assets/Scenes  
- Click Play in the Unity Editor
